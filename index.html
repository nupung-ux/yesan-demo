이 프로그램은

학년, 학급, 전담에 배부된 예산이 무엇이고 얼마 남았는지 한눈에 보고, 품의 제목과 개요, 품목 파일을 만들어 에듀파인에 붙여 넣는 프로그램입니다. 로그인은 필요 없고, 안내받은 주소로 접속해 왼쪽에서 역할을 고르면 됩니다.

역할누가들어가는 방법
예산 사용자담임, 학년부장, 전담학년 또는 전담 이름을 고르면 바로 들어갑니다
예산배정 담당자예산을 배부하는 담당 교사이름을 고르면 비밀번호를 묻습니다 (처음이면 "담당자 등록하기")
관리자프로그램 관리 교사왼쪽 맨 아래 "관리자" → 비밀번호

내 학급 기억하기

예산 사용자로 들어갈 때 "이 컴퓨터에 내 학급 기억"이 켜져 있으면, 다음부터는 주소를 열자마자 우리 반 화면이 바로 열립니다. 마지막에 보던 반을 기억하므로 반 탭을 바꾸면 그 반이 기억됩니다. 여러 사람이 같이 쓰는 컴퓨터라면 체크를 끄고 들어가고, 기억을 없애려면 왼쪽의 "지우기"를 누르세요.

화면 구성

  • 왼쪽: 역할 고르기, 현재 역할 표시(클릭하면 보던 화면으로), 홈 화면, 사용 설명서
  • 새로고침해도 보던 화면이 유지됩니다. 역할을 바꾸려면 왼쪽에서 다른 역할로 들어가면 됩니다.
  • 화면 맨 위 파란 진행선이 보이는 동안은 저장 중입니다. 사라진 뒤 다음 동작을 하세요.

표에 나오는 말

배정액우리 반(또는 학년, 전담)에 배정된 금액
사용액"기안 완료"에 체크한 품의 금액의 합. 잔액에서 빠집니다
예정액아직 작성 중인 품의 금액. 잔액에서 빼지 않습니다
원인행위에듀파인에서 실제 집행된 금액(담당자가 품의목록을 반영하면 들어옴). 사용액과 다르면 노란색으로 표시
잔액배정액 − 사용액

한 해의 흐름

  1. 예산배정 담당자가 예산을 등록하고 학년과 전담에 배부
  2. 학년부장이 학년 예산을 반별로 분배(필요한 경우)
  3. 담임과 전담이 품의를 만들어 제목, 개요, 품목 파일을 에듀파인에 넣고 기안 → "기안 완료" 체크
  4. 담당자가 에듀파인 품의목록을 올려 실제 집행액(원인행위)을 반영
  5. 학년도가 끝나면 관리자가 백업 후 "새 학년도 시작"

담임, 전담 선생님

1. 내 예산 확인

왼쪽에서 학년을 고르고 들어가면 위쪽에 "N학년 전체"와 반 탭이 나옵니다. 우리 반 탭을 누르면 우리 반 예산 표가 나옵니다. 전담은 탭 없이 바로 내 예산이 보입니다. 처음 한 번 들어가면 다음부터는 우리 반이 바로 열립니다(시작하기 탭의 "내 학급 기억하기").

우리 반에 예산이 안 보이면 학년부장이 아직 반별로 분배하지 않은 것입니다. 학년 전체 탭에서 학년 공통으로 쓰거나, 학년부장께 분배를 요청하세요.

2. 품의 만들기

  1. 예산 표에서 쓸 예산 행을 클릭 → 새 품의 만들기
  2. ① 품의서: 왼쪽 양식 칸에서 담당자가 정한 제목 양식을 고르면 제목이 채워집니다. 복사를 눌러 에듀파인 제목에 그대로 붙여 넣으세요. (제목을 그대로 써야 나중에 에듀파인 집행액이 자동으로 맞춰집니다)
  3. 품의 개요: 문구(물품, 업추비 등)를 고르고 용도와 구매처를 넣으면 개요가 만들어집니다. 필요하면 바로 고친 뒤 개요 복사.
  4. ② 품목 입력: 내용, 수량, 예상단가는 필수이고 합계는 자동입니다. 내용을 쓰고 어느 칸에서든 Enter를 누르면 다음 행이 생깁니다. 엑셀에서 복사해 첫 칸에 붙여 넣어도 되고, 견적서 파일을 이 칸에 끌어다 놓으면(여러 개 가능) 품목이 바로 들어옵니다. 지마켓, 아이스크림몰, 학교장터, 아람과학사, 이마트몰, YES24 견적서와 에듀파인 품목내역 양식을 읽습니다. ✨ AI로 읽기 버튼이 보이는 학교(관리자가 Gemini 키를 넣은 경우)는 쇼핑몰 장바구니 화면의 글을 복사해 붙여 넣거나 화면 캡처를 붙여 넣기(Ctrl+V)만 해도 품목을 읽어 줍니다. 읽은 결과는 확인 후 넣습니다.
  5. 에듀파인 업로드 양식 버튼으로 xlsx를 내려받아 에듀파인 품의의 품목 업로드에 넣으면 물품이 한 번에 등록됩니다.
  6. 에듀파인에 기안을 올렸으면 기안 완료에 체크하고 저장. 이때부터 사용액과 잔액에 반영됩니다.
  • 실제 품의 금액이 품목 합계와 다르면(배송비 등) "품목 합계 수정"에 체크하고 금액을 넣으세요. 그 금액이 사용액이 됩니다.
  • 품의를 고치려면 목록에서 품의를 클릭해 수정 후 저장, 잘못 만든 품의는 품의 삭제.
  • 견적서가 읽히지 않으면 안내창이 뜹니다. 쇼핑몰에서 견적서를 엑셀(또는 이마트몰은 PDF)로 저장한 파일을 쓰세요.

3. 학년 공통 품의에 우리 반 물품 담기

학년부장이 "각 학급에서 물품 담기"로 만든 공통 품의가 있으면 예산 표 아래에 초록색 칸으로 학년 공통 품의에 우리 반 물품 담기 목록이 나옵니다. 우리 반 예산(파란 "우리 반" 표시)과는 다른 것입니다. 열어서 우리 반 물품만 넣고(견적서 끌어놓기도 됩니다) 저장한 뒤 담기 완료에 체크하세요. 반당 한도가 정해져 있으면 함께 표시됩니다. 금액은 학년 공통 예산에서 나가므로 우리 반 잔액은 줄지 않습니다.

예산배정 담당자가 "담당자가 모아서 품의"로 배부한 예산(학습준비물 등)은 새 품의를 만들지 않고 물품만 담습니다. 기본은 학년에서 한꺼번에 담는 것이고, 학년부장이 학년 전체 탭의 품의에서 "각 학급에서 물품 담기"를 켜고 반당 한도를 정하면 각 반 화면에 담기 칸이 나타납니다.

학년부장 선생님

담임 기능(담임, 전담 탭 참고)에 더해 N학년 전체 탭에서 학년 예산을 다룹니다.

  1. 학년을 고르면 "N학년 전체" 탭이 먼저 열립니다. 학년에 배부된 예산과 공통, 반별 금액이 한 표에 보입니다. 각 칸 아래 작은 숫자가 잔액입니다.
  2. 반별로 나눠 쓸 예산은 행 끝의 분배 → 반별 금액 입력 → 저장. 나누지 않은 금액은 자동으로 학년 공통에 남습니다. 이미 사용한 금액보다 작게는 줄일 수 없습니다.
  3. 분배 창의 버튼: 학년 배정액 반별 균등은 학년 배정액 전체를 반별로 똑같이 나누고(공통에서 이미 쓴 금액은 남김), 남은 공통 잔액 반별 균등은 학년 공통으로 쓰다가 남은 잔액만 반별로 똑같이 나눠 더합니다. 학기 중에 공통 품의를 하고 남은 돈을 반별로 돌릴 때 씁니다.
  4. 학년이 함께 쓰는 예산은 나누지 말고 예산 행을 클릭해 학년 공통 품의를 만듭니다. 만드는 방법은 담임 품의와 같습니다.
  5. 반마다 물품을 고르고 학년이 한 번에 품의하려면, 공통 품의를 만들 때 각 학급에서 물품 담기를 켜고 반당 한도를 정하세요. 각 반 담임이 자기 화면에서 물품을 담으면 공통 품의의 품목에 반 표시와 함께 모이고, 표 위에서 반별 담긴 금액과 완료 여부가 보입니다. 다 모이면 제목과 개요를 만들어 기안합니다.
담당자가 배부할 때 "학급 균등분배"를 켰다면 이미 반별로 나뉘어 들어옵니다. 분배를 다시 열어 금액을 고칠 수 있습니다.

예산배정 담당자

들어가기

처음이면 왼쪽 "처음이라면 담당자 등록하기"에서 이름과 비밀번호를 정합니다. 비밀번호를 잊으면 관리자에게 초기화를 요청하세요.

1. 예산 등록

  • 에듀파인 예산 구조대로 세부사업, 세부항목명, 원가통계비목, 산출내역, 예산액을 넣습니다. 산출내역이 예산 이름으로 화면에 쓰입니다.
  • 양식 다운로드 (xlsx)로 양식을 받아 채운 뒤 파일로 가져오기를 하면 한 번에 들어갑니다. 엑셀에서 여러 행(6열)을 복사해 첫 칸에 붙여 넣어도 됩니다.
  • 행 끝의 ⧉ 로 행을 복사하면 비슷한 항목을 빠르게 넣을 수 있습니다. 마지막에 등록(저장).
  • ✨ AI로 읽기(관리자가 Gemini 키를 넣은 학교): 에듀파인 예산 화면을 캡처해 붙여 넣으면 세부사업, 세부항목명, 원가통계비목, 산출내역, 예산액을 읽어 표에 넣어 줍니다. 목록이 길면 여러 장을 넣고, 숫자는 꼭 한 번 확인하세요.

2. 예산 배부

예산 하나를 여러 대상에게한 예산을 여러 학년, 전담에. 모두 같은 금액 / 대상마다 다른 금액(학년별로 직접 입력) / 총액을 똑같이 나눔 / 인원 × 인당 금액 중 선택. "잔여 전액"으로 남은 금액을 모두 배부할 수 있습니다
학년별 예산을 한꺼번에"1학년…", "2학년…"처럼 학년별로 등록된 예산을 한 번에. 이름에서 학년을 읽어 대상을 자동으로 맞춥니다
  • 학급 균등분배를 켜면 학년 배부액을 반별로 나눠 넣고 나머지를 학년 공통에 둡니다(학년부장이 나중에 고칠 수 있음).
  • 품의 방식: "학년, 전담이 각자 품의"가 기본입니다. "담당자가 모아서 품의"(학습준비물 등)를 고르면 학년과 전담은 새 품의를 만들 수 없고 물품만 담으며, 담당자가 배부 현황의 취합 품의서에서 제목, 개요, 업로드 양식을 만들어 한 번에 기안합니다(기안 완료 체크 시 각 학년 사용액에 반영).
  • 예산 설명은 학년 화면에 그대로 보입니다. 쓰임새, 기한, 주의할 점을 적어 두세요.
  • 품의 제목에는 {학년·학급}을 넣는 것을 권합니다(넣지 않아도 배부는 됩니다). 학급 품의에서는 "4학년 1반", 학년 공통 품의에서는 "4학년", 전담이면 전담 이름으로 바뀝니다. 예: "{학년·학급} 교육과정운영비 물품 구입" → "4학년 1반 교육과정운영비 물품 구입". 여러 개 등록하면 학년에서 골라 씁니다. 이 제목이 에듀파인 반영 때 품의를 찾는 기준입니다.
  • 품의 개요 문구는 이 예산에서만 쓸 본문 틀입니다. 비워 두면 관리자 기본 문구를 씁니다.
  • "이전 배부에서 설명, 제목, 문구 불러오기"로 지난 설정을 다시 쓸 수 있습니다.

3. 배부 현황

학년과 전담이 각자 품의하도록 배부한 예산별로 대상, 배부액, 사용액, 예정액, 잔액을 봅니다(담당자가 모아서 품의하는 예산은 담당자 품의 탭에 따로 나옵니다). 설명, 제목, 문구는 수정으로 고치고, 금액을 바꾸려면 삭제 후 다시 배부합니다(품의가 있으면 삭제되지 않습니다).

4. 담당자 품의 탭 (담당자가 모아서 품의하는 예산)

  1. 담당자 품의 탭에서 취합 품의서 열기 → 제목을 쓰고(배부할 때는 제목 양식을 정하지 않습니다) 제목 저장. 저장한 제목이 학년, 전담 화면의 담기 목록에 나타납니다.
  2. 각 학년, 반, 전담이 물품을 담으면 담긴 물품에 모입니다. 담기 완료 여부도 함께 보입니다.
  3. 개요를 만들어 복사하고 에듀파인 업로드 양식을 내려받아 기안합니다. 기안했으면 기안 완료 체크.

에듀파인 품의목록 반영은 "에듀파인 반영" 탭을 보세요.

에듀파인 품의목록 반영

에듀파인에서 실제 집행된 금액(원인행위액)을 각 학년, 반, 전담 화면에 넣는 기능입니다. 예산배정 담당자의 "에듀파인 반영" 탭과 관리자의 데이터 탭에 있습니다.

  1. 에듀파인에서 연초부터 현재까지 품의목록을 엑셀로 내려받습니다. 매번 전체 기간을 올리면 됩니다.
  2. 파일 선택 → 제목이 같은 품의를 자동으로 찾아 줍니다. 띄어쓰기는 달라도 됩니다.
  3. 노란색(매칭 안 됨) 행은 드롭다운에서 해당 품의를 고르거나 "무시"를 선택합니다. 프로그램에 아직 없는 품의는 "새 품의로 등록"할 수 있습니다. 한 번 고른 것은 기억합니다.
  4. 반영하기 → 원인행위액이 각 화면의 원인행위 칸에 들어갑니다. 사용액과 다르면 노란색으로 표시되어 비교할 수 있습니다.
선생님들이 품의 제목을 양식 그대로 복사해서 쓰면 거의 모두 자동으로 맞춰집니다. 제목을 다르게 썼다면 한 번만 골라 주면 다음부터는 기억합니다.

테스트 페이지에는 샘플 자료에 맞춘 연습용 품의목록 파일이 있습니다(위쪽 초록 띠의 버튼). 매칭되는 것과 안 되는 것이 섞여 있어 반영 과정을 미리 연습해 볼 수 있습니다.

위쪽 검색 칸에 제목 일부를 넣으면 긴 목록에서 빨리 찾을 수 있고, 이미 반영된 것은 표시되어 다시 고르지 않아도 됩니다.

대상마다 물품 담기용 품의가 자동으로 만들어지고, 학년과 전담은 새 품의를 만들 수 없습니다. 학년에서는 물품을 한꺼번에 담거나, 학년부장이 "각 학급에서 물품 담기"를 켜고 반당 한도를 정해 반별로 담게 할 수 있습니다. 물품이 담기면 담당자 품의 탭의 취합 품의서에서 제목, 개요, 업로드 양식을 한 번에 만듭니다. 학급 균등분배는 쓰지 않습니다.

학년에 알려 줄 내용

이전 배부에서 불러오기
학년에서 골라 쓰는 제목입니다. {학년·학급}을 넣으면 "4학년 1반"(학년 공통이면 "4학년", 전담이면 전담 이름)으로 바뀌어 품의마다 제목이 달라지고, 에듀파인 반영 때 자동으로 맞춰집니다. 넣지 않아도 배부는 됩니다.
품의 제목은 여기서 정하지 않습니다. 배부한 뒤 "담당자 품의" 탭의 취합 품의서에서 직접 씁니다.
